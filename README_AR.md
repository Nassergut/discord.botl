# بوت شــبــاب يـــمــبـــع

بوت حماية Discord باستخدام Node.js و discord.js v14.

## الميزات
- رصد السبام وإسكات العضو مؤقتاً.
- حذف روابط دعوات Discord من غير المصرح لهم.
- تنبيه عند دخول عدد كبير من الأعضاء خلال فترة قصيرة.
- مراقبة حذف الرومات والرتب عبر Audit Log، مع إجراء Anti-Nuke عند تكرار الحذف.
- تسجيل الأحداث في قناة `security-logs` أو القناة المحددة في `LOG_CHANNEL_ID`.
- أمر `/security` لعرض حالة الحماية.

## التشغيل
1. ثبّت Node.js إصدار 20 أو أحدث على الكمبيوتر.
2. فك ضغط الملف وافتح مجلده في Terminal / CMD.
3. نفّذ: `npm install`
4. انسخ `.env.example` إلى ملف اسمه `.env`.
5. ضع توكن البوت في `DISCORD_TOKEN`، وضع أرقام حسابات المالكين في `OWNER_IDS`.
6. نفّذ: `npm start`

## إعداد Discord Developer Portal
1. أنشئ تطبيقاً وبوتاً من https://discord.com/developers/applications
2. فعّل **Server Members Intent** و **Message Content Intent** من صفحة Bot.
3. ادعُ البوت إلى سيرفرك مع الصلاحيات اللازمة: View Audit Log, Manage Messages, Moderate Members, Ban Members, View Channels, Send Messages, Embed Links.
4. لا تعطِ البوت Administrator إلا إذا كنت تعرف سبب حاجتك لذلك. رتبة البوت يجب أن تكون أعلى من رتب الأعضاء الذين سيطبق عليهم الإجراءات.

## ملاحظات مهمة
- لا ترسل توكن البوت لأي شخص ولا تضعه داخل ملفات عامة.
- Anti-Nuke يعتمد على سجل تدقيق Discord وقد يتأخر أو يفشل إذا لم يمتلك البوت صلاحية View Audit Log.
- ابدأ بتجربة البوت في سيرفر تجريبي؛ إعدادات الحماية الآلية قد تعاقب مشرفاً إذا كانت الصلاحيات أو الاستثناءات غير مضبوطة.
- هذا المشروع نقطة بداية عملية، وليس ضماناً لمنع كل أنواع الهجمات أو التخريب.
